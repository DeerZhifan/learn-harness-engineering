# 任务描述:实现知识库应用的文档管理功能

## 背景

这是一个本地知识库应用。基础壳子已经搭好:窗口能启动、左边有文档列表区域、右边有问答面板、本地有数据目录。现在要让这个壳子真正能用。

## 目标

实现下面三个功能。它们组成一条完整的用户路径:**导入文档 → 查看内容 → 关掉应用再打开,文档还在**。

### 功能 1:文档导入流程

用户能从本地选一个 `.txt` 或 `.md` 文件,把它加进知识库。

- 侧边栏有一个导入入口(按钮或类似控件)。
- 触发后弹出文件选择器,只接受 `.txt` 和 `.md`。
- 选中文件后,文档出现在左侧列表里。

### 功能 2:文档详情视图

点击左侧列表里的某个文档,右侧显示它的详情。

- 显示元数据:标题、文件名、导入时间、文件大小。
- 显示完整文本内容,保留原始换行,内容长时可滚动。
- 提供删除按钮,删除后文档从列表消失,选中状态清空。

### 功能 3:文档持久化

应用关闭再重新打开后,之前导入的文档仍然在列表里,点开还能看到内容。删除过的文档不会复活。

## 验收标准

完整跑通下面这条路径才算三个功能都完成:

1. 启动应用,窗口正常出现。
2. 通过导入入口选一个本地 `.md` 文件,它出现在左侧列表。
3. 点击它,右侧显示完整内容和元数据。
4. **关掉应用,重新启动**,这个文档仍然在列表里,点开内容也还在。
5. 点删除按钮,文档从列表消失;再次重启,它没有复活。

任何一步走不通,三个功能就没全部完成。
